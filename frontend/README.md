# GPIO Control Panel — Frontend

A React + TypeScript control panel UI for GPIO automation, built with Vite and deployable as a static bundle on any HTTP server (Apache, nginx, `npx serve`, etc.).

---

## Quick Start — Apache HTTP Server

### Prerequisites

- [Node.js](https://nodejs.org/) v18+ and npm (or pnpm) — **build only**, not needed at runtime
- Apache HTTP Server running on port 80
- Your GPIO server running at **`http://localhost:3000`** (HTTP, not HTTPS)
